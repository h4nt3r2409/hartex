# Screenshots Guide

This folder holds two separate sets of captures. To keep them from looking mixed, here
is what each one is.

- **`en/` — real UI of ARTEX in the default English display language.** This is what the
  fork delivers. The main docs [`../README.md`](../README.md) and
  [`../README.ko.md`](../README.ko.md) use these images. For the delivered English
  screens only, open the [`en/`](en/) folder.
- **The `*.png` files in the root — upstream (Chinese edition) UI captures.** They are
  **preserved as-is** so the fork can be compared 1:1 with the upstream repository, and
  the preserved Chinese README [`../README.zh.md`](../README.zh.md) references them. The
  Korean and English docs do not use them.
- **`wx.png` — the upstream author's WeChat channel promo image.** Kept so that
  [`../README.zh.md`](../README.zh.md) still renders unchanged. It is unrelated to this
  fork.

In short, the Chinese screens you see first in the root are there for upstream
preservation, and the **delivered English screens live in [`en/`](en/).** For why this
fork keeps the originals alongside (localization transparency and upstream comparison),
see the root README.
