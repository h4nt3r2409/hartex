# Screenshots Guide

This folder holds the delivered UI captures for the English edition.

- **`en/` — real UI of Hartex in the default English display language.** These are the
  screens this fork delivers, and the main documentation ([`../README.md`](../README.md))
  uses them. Open the [`en/`](en/) folder to browse the set.
  - `dashboard.png`, `findings.png`, `chat.png`, `tasks.png`, `llm.png`, `login.png`.
  - Captured in the default dark theme at 1440×900; light mode is a secondary preference
    and keeps the same layout and information hierarchy.

The previous Chinese-UI captures in the repository root, and the upstream WeChat promo
image `wx.png`, were removed during the English-only migration. They existed only to
compare the fork with the retired upstream project and are no longer referenced.
